# Galmuri7

`Galmuri7.ttf` is the font currently used for the English `FONT8.FON`
substitution.

It was chosen specifically to provide dense, readable text in the UI, specifically for item/equipment and demon names. A side-effect of replacing this font is that it alters the visual presentation of some existing menus that used English text.
